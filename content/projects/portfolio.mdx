this portfolio was built using modern web technologies focused on minimalism, performance, and iOS-inspired tactile design.

---

## core architecture.

- **nextra 4**: leveraging next.js app router for dynamic, type-safe mdx page mapping.
- **tailwind css v4**: modern styling engine with custom oklch color variables.
- **phosphor icons**: clean, consistent icon set matching apple's sf symbols aesthetic.

```tsx
// sample mdx layout wrapper
export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <main className="max-w-4xl mx-auto px-6 py-8">
      {children}
    </main>
  )
}
```

## implementation highlights.

we integrated **pages cms** to seamlessly edit projects and blog essays directly through github. every interaction is tuned with spring physics and responsive states.
