this is an interactive web tool built to help designers and engineers create harmonized, accessible color systems using the modern **oklch color space**.

unlike traditional rgb or hsl models, oklch represents color based on human visual perception, making it much easier to predict contrast, lightness, and chroma across screen displays.

---

## key features.

- **perceptually uniform**: scaling lightness remains perceptually constant across all hues, ensuring consistent color weight.
- **wcag contrast audits**: instant contrast ratio calculation against dark and light background values.
- **tailwind css export**: exports variables directly into css `@theme` and custom properties.

```ts
// oklch to rgb conversion helper
export function oklchToCss(l: number, c: number, h: number): string {
  return `oklch(${l.toFixed(3)} ${c.toFixed(3)} ${h.toFixed(1)})`
}
```

---

## tech stack & implementation.

built entirely using **react**, **tailwind css v4**, and custom canvas components to visualize chroma gamut boundaries.
